# Find SR-IOV pods in a namespace

List pods in the requested namespace once. Parse each pod's `k8s.v1.cni.cncf.io/networks` annotation (a comma-separated list or JSON objects); a bare network name is in the pod's namespace, while a qualified name specifies a different namespace. Fetch each distinct NetworkAttachmentDefinition (NAD) once. A NAD with `spec.config` JSON `type: sriov` identifies an SR-IOV attachment; other attachments do not rule out an additional SR-IOV NAD on the same pod. Check the pod's `k8s.v1.cni.cncf.io/network-status` for the actual attached network and device PCI address; if it is absent, report VF mapping as unable to verify. If discovery is incomplete, do not conclude the pod has no SR-IOV network.
